    Information
    About

    Build impossible structures by placing vertices and beams on three custom axes. Use the toolbar tools to construct, connect, edit, and delete elements, then save your work as a JSON project file.

    Render Order

    The order of elements in the sidebar determines the rendering order on the canvas. Elements at the top of the list are rendered first, and elements at the bottom are rendered last. You can change the order by dragging and dropping elements in the sidebar in move mode.
